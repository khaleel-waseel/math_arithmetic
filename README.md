# ⚔️ Math Knight Adventures - Kids Arithmetic RPG

A Bookworm Adventures-style Arithmetic RPG game designed for kids to master addition (with & without carry) and subtraction (with & without borrow).

## 🎮 Features
- **4 Epics Books & 16 Interactive Stages**:
  - Book 1: Whispering Woods (Basic Addition - No Carry)
  - Book 2: Cloud Kingdom (Addition with Carry)
  - Book 3: Crystal Caverns (Basic Subtraction - No Borrow)
  - Book 4: Dark Nether Citadel (Subtraction with Borrowing)
- **Column Arithmetic & Regrouping**: Interactive carry bubbles and borrow-strike columns.
- **Battle Mechanics**: Combo streaks, damage popups, potions (Heal, Power, Shield), artifacts, and animated monster combat.
- **🔒 Parent Control Dashboard**:
  - Protected with passcode gate (Default: `1234`).
  - Configure exact digit counts (1-digit to 4-digit) globally or per stage.
  - Custom game rules: Hero Health, Monster Damage (Safe Mode), Timers, and Stage Unlocks.
- **✏️ Scratchpad**: Interactive scratch canvas for working out calculations on screen.

## 🚀 Live Demo & Deployment
This project is built with Vanilla HTML5, CSS3, and JavaScript. It can be hosted on GitHub Pages with zero build configuration.
